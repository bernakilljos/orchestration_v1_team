Give a **cold, expert critique**. No praise. No softening. Just what's wrong and how to fix it.

Structure:
1. **Critical flaws** (blockers — must fix)
2. **Significant issues** (important — should fix)
3. **Minor problems** (nice to fix)
4. **One thing that would make the biggest difference** — the single highest-leverage improvement

Be specific. Reference exact lines/sections/decisions. Don't say "consider improving X" — say "X is wrong because Y, fix it by doing Z".
