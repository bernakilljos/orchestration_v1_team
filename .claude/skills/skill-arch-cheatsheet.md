# Skill: Architecture Cheatsheet

## 목적
프로젝트·시스템·언어의 모든 핵심 정보를 A4 1장에 압축. 학습용·복습용·신규팀원 온보딩용.

## 트리거 (자동 활성화 키워드)
- "치트시트", "컨닝페이퍼", "한 장 요약", "레퍼런스 카드", "정리표", "한 장에"
- 영어: "cheatsheet", "reference card", "one-pager", "quick reference"
- **자동 판단 신호**: 주제가 "정보 밀도 ↑ + 빠른 스캔용" (프로젝트 구조, 명령어 모음, API 레퍼런스)

## 디자인 규칙 (Brij Pandey 스타일)

### 레이아웃 (3컬럼)
```
┌──────────────────────────────────────────────┐
│  Title (큰 검정 굵은 글씨)                     │
│  By: <author>                                  │
├──────────┬───────────────────┬───────────────┤
│ 좌측 25%  │ 중앙 50%           │ 우측 25%      │
│ 폴더 트리 │ 컨셉 블록 (그리드) │ 코드 스니펫   │
│           │                    │               │
│ project/  │ ┌────┐ ┌────┐    │ ```json      │
│ ├ src/    │ │Block│ │Block│   │ {            │
│ │ ├ a.ts  │ └────┘ └────┘    │   "key": ... │
│ │ └ b.ts  │ ┌────┐ ┌────┐    │ }            │
│ ├ test/   │ │Block│ │Block│   │ ```          │
│ └ pkg.json│ └────┘ └────┘    │               │
├──────────┴───────────────────┴───────────────┤
│  Footer (저자·버전·날짜)                       │
└──────────────────────────────────────────────┘
```

### 컬럼별 컨텐츠

**좌측 (트리)**:
- 모노스페이스 폰트
- ASCII 트리 문자: `├─ │ └─`
- 깊이 3~4 레벨까지

**중앙 (블록)**:
- 6~10개 블록을 2×3 또는 3×3 그리드
- 블록당: 제목(굵게) + 항목 4~6개 (• bullet)
- 색상: 박스 헤더 색만 다양화 (파스텔), 본문은 흰 배경

**우측 (코드)**:
- 1~3개 코드 스니펫
- 검은 배경 + 색별 syntax highlight
- 각 30줄 이하

### 색상 팔레트
```
배경:           라벤더/연파랑 (#F0F0FA)
블록 헤더:       각 다른 파스텔
블록 본문:       흰색 (#FFFFFF)
코드 배경:       다크 그레이 (#2D2D2D)
코드 텍스트:     초록 (#7EC07E) / 살몬 (#FF8888)
트리 폴더명:     보라 (#7B61FF)
트리 파일명:     검정 (#2D2D2D)
```

## 실행 흐름

### Step 1 — 정보 수집
주제에서:
1. 프로젝트/시스템 폴더 구조 (좌측)
2. 핵심 컨셉 6~10개 + 각 4~6 bullet (중앙)
3. 1~3개 핵심 코드 스니펫 (우측)

JSON:
```json
{
  "title": "<주제> Project Structure",
  "author": "<who>",
  "tree": "project/\n├── ...\n",
  "blocks": [
    {"title": "Project Overview", "items": ["..."]},
    {"title": "Key Components", "items": ["..."]}
  ],
  "snippets": [
    {"name": "config.json", "lang": "json", "code": "..."}
  ]
}
```

### Step 2 — 렌더 도구 (우선순위)
1. **HTML + wkhtmltopdf** (1순위): 3컬럼 grid 레이아웃 자유도 ↑
2. **ReportLab** (2순위): PDF 직접, 컬럼 수동 배치
3. **python-pptx** (3순위): A4 비율 1슬라이드 (3 textframe)
4. **Markdown + Pandoc** (4순위): 단순

### Step 3 — 출력
- `outputs/arch/cheatsheet-{slug}-{date}.pdf`
- 동반: `outputs/arch/cheatsheet-{slug}-{date}.md`

## 품질 체크
- [ ] 3컬럼 비율 25/50/25
- [ ] 중앙 블록 6~10개
- [ ] 코드 스니펫 30줄 이하
- [ ] 1 페이지에 수렴
- [ ] 폰트 크기 8pt 이상

## 안티패턴
- ❌ 컬럼 비율 깨짐
- ❌ 블록 본문이 박스 넘침
- ❌ 코드가 너무 길어 가독성 저하
