# Skill: Claude Ask (Structured Questions)

## 목적
요구사항 수집·옵션 결정·기획 입력 받기 단계에서, 자유텍스트 응답이 아닌 **구조화된 폼**으로 사용자 입력을 받음. 정확도 ↑, 누락 ↓, 답변 시간 ↓.

## 트리거
- 한국어: "물어봐줘", "선택지로", "옵션 줘", "폼으로", "구조화 질문"
- 영어: "ask user question", "form", "options", "structured input"
- **자동 신호**: 한 번에 결정해야 할 항목이 3개 이상이고 각각 분류 가능할 때

## 필드 타입
| type | 예시 |
|------|------|
| single_choice | A/B/C 중 하나 |
| multi_choice | 체크박스 여러 개 |
| text | 자유 입력 (max_length 권장) |
| number | 정수·소수 (min/max) |
| date | YYYY-MM-DD |
| boolean | yes/no |

## 설계 규칙
1. **3~7 필드** — 8개 이상은 그룹화하거나 2단계로 분리
2. **default 명시** — 가능한 모든 필드에 (이탈률 ↓)
3. **required 최소화** — 정말 없으면 진행 불가한 것만
4. **순서**: 쉬운 것 → 어려운 것 (워밍업)
5. **예시 포함** — placeholder 또는 hint 로

## 출력 포맷 (대화창)

```
📋 <topic>

1. <label> [필수]
   ( ) opt1   (•) opt2 ← 기본   ( ) opt3
   답:

2. <label> [선택, 예시: "2026-05-01"]
   답:

3. <label> [선택, 200자 이하]
   답:

→ 한 줄씩 답해주세요. "기본값으로" = default 사용.
```

## 안티패턴
- ❌ 8개 이상 (그룹화 필요)
- ❌ 자유텍스트만 (구조화 의미 ×)
- ❌ default 0개 (피로 ↑)
- ❌ "기타" 옵션 남발 (분류 무의미)
