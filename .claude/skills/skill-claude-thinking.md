# Skill: Claude Extended Thinking

## 목적
단순 답변이 아닌 **명시적 단계 분해 + 트레이드오프 비교**로 정확도가 중요한 문제 해결. 사고 과정을 사용자가 검증·반박 가능하게.

## 트리거
- 한국어: "깊게 생각해", "단계적", "트레이드오프", "신중하게", "근본 원인"
- 영어: "extended thinking", "carefully", "step by step", "tradeoff"
- **자동 신호**:
  - 답변에 "여러 접근이 가능"이 있을 때
  - 사용자가 "왜 X 가 Y 보다 나은가" 류
  - 디버깅에서 증상이 아닌 원인 추적
  - 알고리즘 복잡도·자료구조 결정

## 가치 매트릭스

| 가치 ↑ | 가치 ↓ |
|--------|--------|
| 알고리즘 설계 | 단순 코드 수정 |
| 아키텍처 결정 | 파일 읽기 |
| 디버깅 (근본 원인) | 포맷팅 |
| 비교·트레이드오프 | 단순 검색 |
| 수학·증명 | 출력 변환 |

## 8단계 프레임

```
1. 문제 재정의   — 사용자 의도 명확화 (2~3 문장)
2. 제약·전제     — 무엇이 주어졌고 무엇이 빠졌는가
3. 후보 생성 3개  — A·B·C
4. 트레이드오프    — 표 형태 (수치·복잡도 명시)
5. 선택 + 근거    — 1순위 + 2~3 문장
6. 약점·실패      — 1순위가 깨질 시나리오
7. 보완책        — 약점 대응
8. 최종 권장      — 구체적 다음 행동
```

## 트레이드오프 표 (필수 컬럼)

| 항목 | A | B | C |
|------|---|---|---|
| 시간복잡도 | O(n) | O(n log n) | O(n²) |
| 공간복잡도 | O(1) | O(n) | O(n) |
| 구현난이도 | 낮음 | 중간 | 높음 |
| 유지보수 | 좋음 | 보통 | 나쁨 |
| 외부 의존 | 없음 | 1 | 3 |

## 안티패턴
- ❌ 단순 문제에 적용 (낭비, "Hello World 어떻게?" 에 8단계)
- ❌ 단계 분해 없이 긴 글 (가독성 ↓)
- ❌ 후보 1개만 (트레이드오프 의미 ×)
- ❌ 정성 표현만 ("좋다/나쁘다" — 수치·복잡도 필요)
- ❌ 결론 모호 ("상황에 따라" 만)
