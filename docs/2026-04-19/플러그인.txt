주요 경로:
  - plugins/<name>/           : 소스 오브 트루스 (편집 여기만)
  - .claude/commands/*.md     : sync 결과물 (/<cmd> 슬래시 커맨드)
  - .claude/skills/*.md       : sync 결과물 (Skill 툴에서 사용)
  - .claude/scripts/sync-plugins.sh : 동기화 스크립트

사용법:
  1) plugins/ 에서 편집
  2) bash .claude/scripts/sync-plugins.sh
  3) git commit plugins/ + .claude/
