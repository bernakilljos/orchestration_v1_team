# Skill: Architecture Layered Cake

## 목적
시스템·스택·프로세스를 **계층(layer)** 단위로 1페이지 인포그래픽화. 좌측 아이콘 컬럼 + 레이어별 다른 배경색 + 코드 블록 임베드.

## 트리거 (자동 활성화 키워드)
- "레이어 케이크", "층층이", "스택", "계층 구조", "단계별"
- 영어: "layer cake", "stack diagram", "tier", "layered architecture"
- **자동 판단 신호**: 주제가 "맨 위 ~ 맨 아래 순서가 의미 있음" (의존 관계, 빌드 순서, OSI 모델)

## 디자인 규칙 (Brij Pandey 스타일)

### 레이아웃
```
┌──────────────────────────────────────┐
│  Title (큰 검정 굵은 글씨)             │
├──────────────────────────────────────┤
│ 🎯  TOP FLOOR — '<이름>'              │ ← 살구색
│     항목1, 항목2, 항목3               │
├──────────────────────────────────────┤
│ 🤖  LAYER 5 — '<이름>'                │ ← 라일락
│     본문 + 작은 코드 박스             │
├──────────────────────────────────────┤
│ ⌨️   LAYER 4 — ...                   │ ← 블루
├──────────────────────────────────────┤
│ 🔌  LAYER 3 — ...                    │ ← 그린
├──────────────────────────────────────┤
│ 🧠  LAYER 2 — ...                    │ ← 옐로우
├──────────────────────────────────────┤
│ 📦  LAYER 1 — ...                    │ ← 코랄
├──────────────────────────────────────┤
│ FOUNDATION — '<런타임>' (비교표)      │ ← 그레이
└──────────────────────────────────────┘
```

### 색상 팔레트 (레이어별 파스텔)
```
TOP:        살구  (#F4D5C2)
LAYER 5:    라일락 (#D5C7E8)
LAYER 4:    블루   (#C2D5E8)
LAYER 3:    그린   (#C7E8C2)
LAYER 2:    옐로우 (#E8DCC2)
LAYER 1:    코랄   (#E8C2C2)
FOUNDATION: 그레이 (#E0E0E0)
좌측 아이콘 박스: 각 레이어 색의 진한 톤
```

### 텍스트 규칙
- 레이어 제목: `LAYER N — '<별칭>'` (모두 대문자)
- 본문: 항목 3~6개 / bullet 또는 inline
- 코드 박스: 검은 배경 + 녹색 텍스트 (선택, 1~2줄만)

## 실행 흐름

### Step 1 — 레이어 추출
주제에서 5~7개 레이어 식별:
- 가장 추상적 / 사용자 가까움 = TOP
- 가장 구체적 / 하드웨어 가까움 = FOUNDATION
- 각 레이어 간 의존 관계 명확

JSON:
```json
{
  "title": "<주제> Architecture Reference",
  "layers": [
    {
      "level": "TOP",
      "name": "Workflow Patterns",
      "icon": "🎯",
      "color": "apricot",
      "items": ["Architect: A→B→C", "Creator: ..."],
      "code": "예시 1줄"
    }
  ],
  "foundation": {
    "name": "Runtime",
    "comparison_table": [...]
  }
}
```

### Step 2 — 렌더링 (우선순위)
1. **python-pptx** (1순위): A4 비율 1슬라이드, 정밀 박스 배치
2. **ReportLab** (2순위): PDF 직접
3. **HTML + wkhtmltopdf** (3순위): 디자인 자유도 높음
4. **Markdown + Pandoc** (4순위): 가장 단순, 디자인 제한

### Step 3 — 출력
- `outputs/arch/layered-{slug}-{date}.pdf` (또는 `.pptx`)
- 동반: `outputs/arch/layered-{slug}-{date}.md` (구조 원본)

## 품질 체크
- [ ] 레이어 5~7개 (4 이하·8 이상 금지)
- [ ] 각 레이어 색 구별됨
- [ ] 좌측 아이콘 일관성
- [ ] 위→아래 의존 방향 명확
- [ ] 1 페이지에 수렴

## 안티패턴
- ❌ 레이어 8개 이상 (분할)
- ❌ 같은 색 인접
- ❌ 본문이 박스 넘침
