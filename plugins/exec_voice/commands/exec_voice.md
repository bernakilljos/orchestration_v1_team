# /exec_voice — 음성 처리 허브

## 포함 커맨드
- `/transcribe` — 오디오 파일 → 텍스트 (Whisper STT)
- `/speak` — 텍스트 → 음성 (TTS)
- `/meeting` — 회의 녹음 → 회의록 자동 생성
- `/convert` — 오디오 포맷 변환
- `/voice-task` — 음성으로 작업 지시
- `/voice-status` — 음성 플러그인 상태

## 기본 실행
용도에 따라 `/transcribe` (듣기) 또는 `/speak` (말하기) 사용.
